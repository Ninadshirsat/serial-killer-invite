# सिरियल किलर – शतक महोत्सवी (१०० वा) प्रयोग · Invitation

Live site: https://serial-killer-invite.vercel.app

## Editing
- All show details (date, time, venue, cast, links) are in `index.html`, inside the
  `const INVITE = { ... }` block near the bottom of the file.
- Images live in `img/`:
  - `og.jpg` – picture shown when the link is shared on WhatsApp (1200×630)
  - `logo.webp`, `emblem.webp`, `poster-main.jpg`, `card.jpg`

Every change pushed to the `main` branch is deployed to Vercel automatically.
